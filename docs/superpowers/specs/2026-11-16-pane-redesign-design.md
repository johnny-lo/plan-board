## 4. 顏色

- 只用 theme key，不寫 hex 或 `"black"`。mod 讀不到深淺色；Johnny 的 terminal 把 theme 色畫成終端機自己的 16 色，數值不能假設。
- **鋪底只剩 1 格色條**（卡片色線、細節色條），兩種 theme 都看得到（C1）。**字不鋪底**：一般字、淡字、彩色字都畫在 pane 的底上，兩種 theme 都讀得到。
- **膠囊用 `inverse`**：`<Text inverse color="suggestion">`，不設 `backgroundColor`、不粗體。反白後底是語意色、字是 pane 自己的底色；這些 key 本來就是在 pane 底上寫字用的，反過來是同一對對比，深淺色都成立。未實測：R1 和 `backgroundColor`＋`inverseText` 並排看。
- 色塊上不用粗體：第一輪看不清的琥珀標頭、選中分頁都是粗體；但「做完」不是粗體也看不清，原因不確定。

| 語意 | 用在 | key |
|---|---|---|
| 進行中 | 「進行中」「建議」膠囊、選中分頁、進度條實心、● | `suggestion` |
| 要你處理 | 第一張卡色線與標頭、⚑、等你的字與數字、band 等你膠囊、直接改過的警告 | `warning` |
| 做完、已暫存 | ✓、「做完」膠囊、已暫存色線、「已選」「目前沒有等你的事」 | `success` |
| 中性 | 其他卡色線、細節色條 | `inactive` |
| 已送出 | 色線（ANSI theme 下可能同 `inactive`，靠淡字和「已送出」分） | `subtle` |
| 次要字 | 時間、指派、麵包屑、細節、收合列、進度條框 | `dimColor` |

拿掉的：面板底色（C3、C4）；`subtle`＋`text` 和 `success`＋`inverseText` 的膠囊（C6 深色難讀）。不靠顏色也分得出：步驟留 ✓●○⚑，狀態、卡種、「已選」「已送出」都寫成字。

## 9. 細節區塊

- `detailBlock(key, detail, indent)`：外層 Box `paddingLeft: indent - 2`，裡面橫排：`stripe('inactive')`，再一個 `paddingLeft: 1` 的直排 Box，每行一個淡字 Text（`wrap="wrap"`），空行畫成一個空白（細節設計第 5 節第 10 條）。
